# こどもタイマー(3歳児向け時間管理Webアプリ)

アナログ時計・残り時間・今やることのイラストを大きく見せ、「おわったよ」で次の予定へ進める、幼児向けの時間管理アプリです。保護者は設定画面(パスワードロック付き)で予定・画像・配色を編集します。

## しくみ

- **アプリ本体**(コードだけ・公開してよい)→ GitHub Pages で公開
- **データ**(予定・画像・配色)→ あなたの **非公開(Private)リポジトリ** に保存
- スマホで設定を変えると、数秒後に自動でデータ用リポジトリへ保存されます。
- 最初の画面で **コード** を入れるとつながります。**この端末では、いちど入れれば次回からは入力なしで開きます。**
- サーバー(Supabaseなど)は使いません。

## はじめての設定(最初の1回だけ)

### 1. データ用の非公開リポジトリを作る
GitHubで **New repository** → 名前は例えば `kids-timer-data` → **Private** を選び、「Add a README file」にチェックして作成。

### 2. アクセストークンを作る
GitHub右上のアイコン → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** → さきほどのデータ用リポジトリだけ
- Permissions → Repository permissions → **Contents: Read and write**
- 有効期限は最長1年。切れたら作り直して、コードを入れ直します。
- 表示される `github_pat_…` をコピー(あとで見られません)。

### 3. アプリを開いて、つなぐ
アプリのURLを開く → **「はじめて使う(コードをつくる)」** → リポジトリ名(`ユーザー名/kids-timer-data`)とトークンを入力 → **つなぐ**。
非公開でないリポジトリには接続を拒否します(子どもの画像が読まれないように)。

### 4. 設定
「せってい」→ ロックのパスワードを設定 → 活動・プリセット・曜日を登録。変更は自動でGitHubに保存されます。

### 5. ほかの端末で使う
最初の端末の **せってい → 同期・通信 → コードを表示する** で出る `kt1.…` のコードを、ほかの端末の最初の画面に貼り付けて「ひらく」。ロックのパスワードも共有されます。
> コードにはトークン(書き込み権限)が入っています。他の人に見せないでください。

## アプリを公開する(GitHub Pages)

アプリ本体は **データ用とは別の** リポジトリ(公開でOK、例 `kids-timer`)に置きます。データやトークンはコードに入りません。

1. アプリのリポジトリに、このフォルダの中身を push(ブランチ `main`)。
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
3. `main` に push すると `.github/workflows/deploy.yml` が、テスト→ビルド→公開を実行。URLは `https://<ユーザー名>.github.io/<リポジトリ名>/`。
4. スマホで開き、ホーム画面に追加すると全画面で使えます。

環境変数・Secretsの設定は不要です。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # 単体テスト
npm run build   # 型チェック + 本番ビルド
```

## 同期の動き

- 画面は常に端末内のデータを見ます(オフラインでも動作)。
- 設定を変えると約2.5秒後に自動でGitHubへ保存。アプリを開いたとき・画面に戻ったとき・1分おきに、ほかの端末の変更を取り込みます。
- この端末とGitHubの**両方**が別々に変わっていたら、勝手に上書きせず「GitHubの内容にする / この端末の内容で上書き」を選ぶ画面が出ます。
- 保存先: `kids-timer/data.json`(設定)と `kids-timer/images/`(画像)。変更履歴はGitHubのコミットとして残るので、前の状態に戻すこともできます。

## ロックのパスワードを忘れたとき

データ用リポジトリの `kids-timer/data.json` をGitHubのWeb画面で開いて編集し、`"lockSalt"` `"lockHash"` `"lockIterations"` の3つの値を `null` にして保存します。次にアプリを開くと同期され、設定画面で新しいパスワードを作れます(端末側に未保存の変更が残っている場合は、競合の選択画面で「GitHubの内容にする」を選びます)。

## バックアップ・復元

設定 → バックアップで、JSON(画像込み)を書き出し/読み込み。ロックのパスワード情報は含みません。

## 既知の制限

- 実際のGitHubとの通信は、開発環境では模擬サーバーでしか確認できていません。初回は実機で、つなぐ→保存→別端末で開く、を確認してください。
- 画像を差し替え・削除しても、GitHub上の画像ファイルは残ります(孤立画像の自動削除なし)。
- 画像はオンライン時にGitHubへ送られます。オフライン中に追加した画像は、つながったときに送られます。
- 同期は設定全体を1ファイルで管理するため、2台で同時に編集した場合は上の「競合」の選択になります(項目ごとの自動マージはしません)。
- トークンはこの端末のブラウザ内に保存されます。端末を手放すときは「接続を解除」してください。トークンが漏れたら、GitHubでそのトークンを削除(Revoke)してください。
- ロックは画面上の保護です。データの保護は「非公開リポジトリ」と「トークン」が担います。
- 時計の塗りつぶしは「分針の現在位置から終了時刻の位置まで」の扇形。
- 予定の並べ替えは隣の枠との入れ替え。祝日計算は 2000〜2099 年。
